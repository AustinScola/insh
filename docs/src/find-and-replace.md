# Find and Replace

The find and replace component can be used to find and replace text.

## Commands
| Command          | Description                                |
|------------------|--------------------------------------------|
| `y`              | Replace the next occurance.                |
| `n`              | Do not replace the next occurance.         |
| `Y`              | Replace all occurances.                    |
| `N`              | Do not replace any occurances.             |
