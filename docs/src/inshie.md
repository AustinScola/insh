# Inshie 

Inshie is an AI chatbot.

| Command          | Description                                |
|------------------|--------------------------------------------|
| `<Ctrl>-q`       | Exit Inshie.                               |
| Any character    | Append the character to the current input. |
| `<Ctrl>-o`       | Append a newline to the current input.     |
| `<Backspace>`    | Remove the last character from the input.  |
| `<Enter>`        | Send the prompt to Inshie.                 |
| `<Ctrl>-e`       | Scroll down.                               |
| `<Ctrl>-y`       | Scroll up.                                 |
| `<Ctrl>-n`       | Start a new conversation.                  |
| `<Ctrl>-h`       | Open the Inshie conversation history.      |

## Inshie Conversation History

View and manage the conversation history for Inshie.

| Command          | Description                                                 |
|------------------|-------------------------------------------------------------|
| `<Ctrl>-q`       | Exit the Inshie conversation history and go back to Inshie. |
| `j` \| `<Down>`  | Move the selection down by one entry.                       |
| `k` \| `<Up>`    | Move the selection up by one entry.                         |
| `J` \| `<End>`   | Move the selection to the last entry.                       |
| `K` \| `<Home>`  | Move the selection to the first entry.                      |
| `l` \| `<Enter>` | Open the selected chat.                                     |
| `<Ctrl>-e`       | Scroll down.                                                |
| `<Ctrl>-y`       | Scroll up.                                                  |
| `n`              | Start a new chat.                                           |
| `/`              | Search past chats.                                          |
| `dd`             | Delete the selected chat.                                   |
